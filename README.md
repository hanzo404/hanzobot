# hanzobot

افزونه‌ها و ابزارهای ووکامرس سایت **ینولایف** (`yenolife.com`) — ساخته‌شده برای قالب وودمارتی و ورود پیامکی (OTP).

| مسیر | چیست |
|---|---|
| [`hanzobot-login-required-cart/`](hanzobot-login-required-cart/) | افزونه‌ی **ورود اجباری برای افزودن به سبد** (نسخه‌ی ۱٫۲٫۵) — مهمان‌ها به صفحه‌ی ورود می‌روند و بعد از ورود با محصول به سبد برمی‌گردند. |
| [`hanzobot-payment-panels/`](hanzobot-payment-panels/) | افزونه‌ی **پنل‌های پرداخت (چند فروشنده / چند قیمت)** (نسخه‌ی ۱٫۰٫۰) — الگوی تکنولایف: قیمت اصلی + پنل اسنپ‌پی و ترب‌پی با درصد دلخواه (مثلاً ۱۳٪)، قفل شدن درگاه پرداخت و ثبت پنل در سفارش. |
| [`demo/index.html`](demo/index.html) | پیش‌نمایش تعاملی پنل‌ها: محاسبه‌ی +۱۳٪، نمایش اقساط و قفل شدن درگاه‌ها در تسویه‌حساب. |

## نصب سریع

فایل ZIP آماده‌ی هر افزونه در ریشه‌ی مخزن است:

- `hanzobot-login-required-cart.zip`
- `hanzobot-payment-panels.zip`

پیشخوان وردپرس → **افزونه‌ها ← افزودن ← بارگذاری افزونه** → نصب و فعال‌سازی.

## تنظیمات

- افزونه‌ی ورود اجباری: بدون نیاز به تنظیم؛ فقط فعال کنید.
- افزونه‌ی پنل‌های پرداخت: **ووکامرس ← پنل‌های پرداخت**. شناسه‌ی درگاه‌ها (مثل `payzito_snapppay`) را از فهرست درگاه‌های همان صفحه تیک بزنید؛ اگر خالی بگذارید، با کلیدواژه (`snapp`, `torobpay`, ...) خودکار تشخیص داده می‌شود.

## پیش‌نمایش

```bash
cd demo && python3 -m http.server 8000
```

سپس در مرورگر: `http://localhost:8000`
